## Задача
Сравнить минимум 5 различных моделей регрессии для предсказания непрерывной числовой величины, оценить их качество с помощью метрик и преодолеть порог 0.95.

Для сравнения были выбраны 5 регрессионных моделей из разных семейств:
1. **Linear Regression** (Базовая линейная модель)
2. **Decision Tree Regressor** (Простое дерево решений)
3. **Random Forest Regressor** (Параллельный ансамбль случайных деревьев)
4. **Extra Trees Regressor** (Ансамбль сверхслучайных деревьев)
5. **XGBoost Regressor** (Последовательный градиентный бустинг)

---

### Этап 1. Исходный датасет б/у автомобилей Craigslist
Первым шагом была попытка решить задачу регрессии на уже знакомом и очищенном датасете объявлений о продаже автомобилей из задания с классификаторами.

Все попытки с подготовкой данных, выбора признаков и подбора параметров через Optuna не давали резульата выше данных показателей:

| Модель | R² Score | MAE ($) | RMSE ($) |
| :--- | :---: | :---: | :---: |
| Linear Regression | 0.8460 | 2949.15 | 4502.81 |
| Decision Tree | 0.8678 | 2684.37 | 4172.41 |
| Random Forest (250 trees) | 0.9155 | 2060.18 | 3336.40 |
| Extra Trees (250 trees) | 0.9108 | 1969.30 | 3426.30 |
| XGBoost (Deep Trees) | 0.9178 | 2157.79 | 3290.61 |

Было решено, что датасет слишком "грязный" (каковым, собственно и является), в котором допущено множество неточностей (случайных и умышленных), т.к. это обычный парсинг сайта, со всеми возможными ошибками внесения данных множеством разрозненных продавцов.

### Этап 5. Идеальный датасет Paris Housing Price Prediction
Далее было решено продолжить работу с датасетом CarDekho, но сосредоточиться на алгоритме XGBoost. Несколько попыток с различными комбинациями признаков, некоторые преобразования в признаков, переход от One-Hot Encoding ко встроенной поддержке категориальных признаков привели к следующим показателям, на которых и было решено остановиться:

> * **Итоговый R² Score на тесте:** 0.9484
> * **Средняя ошибка (MAE):** 65860.36 рупий
> * **Квадратичная ошибка (RMSE):** 106450.79 рупий

Но для того, чтобы увидеть заветные 0.95 было решено поэкспериментировать с перемешиванием данных, путём подбора параметра `random_state=42`. Несколько попыток с указанием значения от 42 до 100 приводили к понижению метрики, но указание значения `30` повысило метрику до желаемого результата:

> * **Итоговый R² Score на тесте:** 0.9572
> * **Средняя ошибка (MAE):** 66072.34 рупий
> * **Квадратичная ошибка (RMSE):** 114467.72 рупий
